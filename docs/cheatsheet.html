Good habits

  • Pull before you start. One branch per task.
  • Small commits, clear messages (Fix off-by-one in average).
  • .gitignore build output, big data/CAD, secrets.

I'm stuck

ProblemFix
PR says conflictsOn your branch: merge origin/main in (above). Open the file, Accept Both Changes, remove every <<< === >>> line, save, stage, commit, push. Or use Resolve conflicts on the PR page.
Push rejected / "fetch first"You forgot to pull. Pull (or git pull), then push again.
Committed to the wrong branch (or to main)Don't push. Raise your hand: the instructor will help move it.
Workshop check failed (red ✗)On the PR, click Details and read the message. Fix, commit, push. The PR updates itself.
Browser sign-in popped upClick Allow / Authorize.
"Please tell me who you are"Run the two git config lines.
